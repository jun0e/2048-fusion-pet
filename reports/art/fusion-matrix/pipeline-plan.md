## 3. Jobs (`tools/pipeline-jobs.mjs`)

**`fusion.<a>+<b>`** (28 jobs), the foe job's structure with the hero cue:

```js
const r = FUSION_ROSTER[key];
return { ...base, model: models.best, bg: r.bg, refs: [fusionSil(key), FUSION_RENDER_REF],
  post: { fit: 'trim', size: 320, palette: [...r.pal, ...UNI], snap: true }, // keeps the cream rim (no stripRim)
  pick: { n: 3, contract: fusionSil(key), view: r.view, grounds: PET_GROUNDS, others, allies, animal: r.animal, pose: r.pose, accepted: r.gateAccepted },
  prompt:
    `${FOE_SIL}${FOE_VIEW[r.view]}` +                     // the same contract and view lines as the foes
    'Image 2 shows the required rendering (outline weight, cel shading, eye style, the cream sticker rim): match it, but not its species or pose. ' +
    `The creature: ${r.desc}, a hero pet named ${r.name}, the fusion of ${A} and ${B}: ${r.from[a]}; ${r.from[b]}. Pose: ${r.pose}. ` +
    `VALUE RULE: ${r.pal[0]} covers most of the body with one crisp cel-shade tone in ${r.cel} over at least a third of it and a highlight in ${r.pal[2]}. ` +
    `HARD COLOUR RULE: body colours only ${r.pal[0]}, ${r.pal[1]}, ${r.pal[2]}; accents only ${r.pal[3]}, ${r.pal[4]}, ${r.pal[5]}; outline ${UNI[0]}, cream rim ${UNI[1]}, black/white eyes. ` +
    `${STICKER} ${bgLine(r.bg)}` };
```

- `PET_GROUNDS = { lane: '#D9C7A3', keep: '#3E3C58' }`: the two grounds pets roam over (`matrix.md` section 5).
- `others` = the 27 other fusions as `{ id: 'fusion.<k>', path: their contract (or the picked sprite once it exists), mask: 'dark' | 'alpha' }` with no `chapters`, so `silhouette-check.py`'s `twin` gate (≤ 0.60) runs over them and its `twinChapter` gate sees an empty pool. `allies` = the 17 foe sprites (`public/assets/gen/enemy.*.png`) plus the 8 base pets (`pet.<el>.128.png`), so the `ally` gate (≤ 0.65) is "no foe look and no parent look": the three targets of the matrix, through the script as it is, with no code change to it.
- Three candidates, the pro model, 512 px, concurrency 1 (the foes' settings); `tools/pick.mjs` keeps the best inside the gates and runs its strict round only when none is.

**`portrait.<a>+<b>`** (28): as today, with the roster replacing `ADULT[a]`/`PART[b]`: `A portrait of the creature in image 1 (${r.name}: ${r.desc}), keeping its exact silhouette, colours, markings and face. Draw this creature only, not any other animal.` Refs: only its own picked fusion sprite (the current rule, which stopped the golden's dragon appearing on every card). Rim light `ELEMENT_PALETTES[b].key`, plate `ELEMENT_PALETTES[a].key`, the vinyl style, 512 px, `fit: 'cover'`.

**`portrait.<a>+<b>.ascended`** (28): unchanged, an edit of the new portrait.

**Everything else** stays: `halo.*` keeps `fusion.fire+ice` as its style reference (after the run that is the red panda, which is fine for outline weight), the `pet.*` chain is untouched, the foes are untouched.

## 4. Gates per candidate (`tools/silhouette-check.py`, gate version 2)

| Gate | Rule | Pool |
|---|---|---|
| contract | IoU with its own contract at 40 px ≥ 0.6 (`mirror` flagged when a profile came back facing right) | `tools/refs/fusions/sil-<key>.png` |
| twin | closest other fusion ≤ 0.60, flip allowed | the 27 contracts, replaced by picked sprites as they land |
| ally | closest foe sprite and closest base pet ≤ 0.65 | 17 `enemy.*.png` + 8 `pet.<el>.128.png` |
| ground | ≥ 1/3 of the body (minus the outline band) separated by ΔL* ≥ 20 | lane `#D9C7A3`, keep `#3E3C58` |

The value rule in the prompt names each pet's cel tone (the lane carrier from `palette-check.json`), which is what makes the ground gate reachable for the eight pale pets. A reviewed near-miss is recorded as `gateAccepted: { margins, why }` in the roster, as the owl, the hive queen and the fox were.
